# O16 + O17 Reserve Memory for Every Sprint and Tell the Agent Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Each server can declare a default memory reservation, which is charged to any sprint placed there that asks for no memory. The ledger then counts every sprint's memory on every server that declares memory. The worker agent is told how much memory its sprint reserved and that its processes must stay under it.

**Architecture:**
- **Storage:** `default_memory_gb` is a new per-server value: `hosts.<name>.default_memory_gb`, or top level for this machine, beside `memory_gb`.
- **Charging:** `Ledger.fit` adds it to a request that omits `memory_gb`, per candidate server, only when that server declares `memory_gb`. `acquire` stores the charged amounts on the lease, so `used()` and every reader see the real reservation.
- **Unrunnable report:** `over_capacity_on` applies the same charge, so it agrees with placement.
- **PM:** the COMPUTE block names each server's default.
- **Dashboard:** the server dialog edits the default in edit mode and for this machine.
- **Worker agent (O17):** the instructions gain a Memory section from the lease's `memory_gb`, on trust, with no enforcement.
- **Not in code:** declaring `memory_gb` and a default on the live servers is a configuration edit the deployment owner makes.

**Tech Stack:** Python 3 (FastAPI, PyYAML, pytest), React + Mantine (vitest).

**Spec:** `docs/superpowers/specs/2026-09-14-multi-host-execution-design.md` (§4 Hosts, request shape as built in O4); todo items O16 and O17.

## Global Constraints

- No commits or pushes without explicit approval; there are no commit steps in this run.
- Python: `~/venvs/coscience/bin/python -m pytest`, prefixed `PYTHONPATH=src` in the worktree (addopts already has `-q`; never add another). Frontend: from `frontend/`, `npx vitest run …` and `npx tsc -b`.
- A server with no `default_memory_gb` (or `0`) behaves exactly as today. A file that never uses the key places every sprint exactly as before.
- The default is charged only on a server that declares `memory_gb`. A server without declared memory never gains a memory charge.
- A request that names `memory_gb` is never changed, even when it is smaller than the default.
- `default_memory_gb` must be a finite non-negative number, and not larger than that server's `memory_gb`. Either violation is a parse error for that server (for this machine, a `host_errors` entry with the key ignored).
- The charged amount is what the lease stores. Nothing recomputes it later from a changed default: a lease keeps what it was granted.
- Nothing enforces memory on processes (no cgroup, no `MemoryMax`). The agent is told; that is all.
- The live `resources.yaml` is not edited by this work.

### Task 1: The ledger charges a server's default memory to sprints that ask for none (O16 backend)

**Files:** resources, ledger, scheduler, dispatcher (placement parts only), service, http_api, pm_agent, pm_claude, `tests/test_default_memory.py`.

**Interfaces:**
- Produces: `Host.default_memory_gb: float = 0.0`.
- Produces: `resources.charged(amounts: dict[str, float], host: Host) -> dict[str, float]`. It returns `amounts` plus `memory_gb: host.default_memory_gb` when `"memory_gb" not in amounts`, `host.default_memory_gb > 0` and `"memory_gb" in host.capacity`; otherwise a copy of `amounts`.
- Produces: `ledger_status()["hosts"][i]["default_memory_gb"]` and `ledger_status()["local_capacity"]` unchanged. The local default is read from the local host row.
- Produces: `update_host(..., default_memory_gb: float | None = None)` (0 removes the key); `HostUpdateIn.default_memory_gb: float | None`; `confirm_host`'s written entry keeps `default_memory_gb` when given (`HostConfirmIn.default_memory_gb: float | None = None`).
- Produces: `set_capacity(capacity, gpus=None, default_memory_gb=None)`, where `None` keeps what is on file and `0` removes it. `CapacityUpdate.default_memory_gb: float | None = None`. `default_memory_gb` is a reserved resource name.
