# O15 Remove a Server With One Button Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A server leaves the pool with one Remove click. A server with nothing on it is gone within a dispatch cycle. One with work on it takes no new work and is gone as soon as that work ends. There is no Drain step and no wait timer.

**Architecture:** Remove writes `remove: true` on the server's entry in `resources.yaml`. A server marked this way takes no new grants. The dispatcher, at the start of every cycle and before it grants anything, deletes each marked server that holds no lease and has no unfinished sprint on it, then refreshes its own in-memory pool. The dispatcher is the only process that grants, and it deletes before it grants, so no human timing is needed: the two-minute `REMOVE_AFTER_DRAIN` wait and the Drain toggle go away. Because the dispatcher now writes the pool file too, every read-modify-write of `resources.yaml` takes one file lock. The card shows what a marked server is waiting on, and a Keep button takes the mark back.

**Tech Stack:** Python 3 (FastAPI, PyYAML, pytest), React + Mantine + TanStack Query (vitest).

**Spec:** `docs/superpowers/specs/2026-09-14-multi-host-execution-design.md` (§7 health, drain and remove as built in O7); todo item O15.

## Global Constraints

- No commits or pushes without explicit approval; there are no commit steps in this run.
- Python: `~/venvs/coscience/bin/python -m pytest`, prefixed `PYTHONPATH=src` in the worktree (addopts already has `-q`; never add another). Frontend: from `frontend/`, `npx vitest run …` and `npx tsc -b`.
- Tests never run ssh or rsync: the dispatcher's host runner is injected, as `tests/test_host_health.py` does.
- Only the dispatcher deletes a server entry, and only at the start of a cycle, before the grant step, after `ledger.load()` and `ledger.expire(now)`.
- A server is deleted only when no lease names it and no sprint that is not DONE, CANCELED or FAILED has `progress.host` or `progress.job_host` equal to its name. This is the same test `remove_host` applies today.
- A marked server takes no new grants, but a sprint whose agent or job is still physically running there is still re-adopted (the existing `readopt` path), exactly as a drained server is treated today.
- Every read-modify-write of `resources.yaml`, in the backend and in the dispatcher, holds `resources.pool_file_lock(repo_root)` for the whole read-modify-write. The substrate commit happens after the lock is released.
- A hand-written `drain: true` keeps meaning "takes no new work". Nothing writes `drain` any more. Keep clears `drain`, `drained_at` and `remove`.
- This machine (`local`) cannot be removed, as today.
- The Remove confirmation prompt stays, reworded as in Task 2. Removing an idle server is not undoable from the dashboard, because re-adding means probing again.

- [ ] **Step 4: `host_removal.py`.**

```python
"""Taking servers out of the pool. A human marks a server (`remove: true`); the
dispatcher deletes it at the start of a cycle, before it grants, once nothing is on it.
The dispatcher is the only process that grants, so deleting there cannot race a grant."""
from coscience.models import SprintStatus
from coscience.resources import pool_file_hosts, pool_file_lock, write_pool_file

_FINISHED = (SprintStatus.DONE, SprintStatus.CANCELED, SprintStatus.FAILED)


def blockers(substrate, ledger, name: str) -> list[dict]:
    out, seen = [], set()
    statuses = {s.id: s for s in substrate.iter_sprints()}
    for lease in ledger.all_leases():
        if lease.host == name and lease.sprint_id not in seen:
            s = statuses.get(lease.sprint_id)
            out.append({"sprint_id": lease.sprint_id,
                        "status": s.status.value if s else "unknown",
                        "reason": "holds a lease here"})
            seen.add(lease.sprint_id)
    for sid, s in statuses.items():
        if sid in seen or s.status in _FINISHED:
            continue
        progress = substrate.load_progress(sid)
        if progress.host == name or progress.job_host == name:
            out.append({"sprint_id": sid, "status": s.status.value, "reason": "its work is here"})
            seen.add(sid)
    return out


def remove_marked(substrate, ledger) -> list[str]:
    repo_root = substrate.repo_root
    removed = []
    with pool_file_lock(repo_root):
        loaded, hosts = pool_file_hosts(repo_root)
        for name, entry in list(hosts.items()):
            if isinstance(entry, dict) and entry.get("remove") is True \
                    and not blockers(substrate, ledger, name):
                del hosts[name]
                removed.append(name)
        if removed:
            write_pool_file(repo_root, loaded)
    return removed
```
